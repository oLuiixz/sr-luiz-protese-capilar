# SR Luiz Barbearia

Site institucional responsivo da SR Luiz Barbearia.

## Desenvolvimento
- Node.js 20+
- `npm install`
- `npm run dev`
- `npm run build`

## Imagens
Coloque as imagens oficiais na pasta `imagens/`. As fotos temporárias do layout serão substituídas pelas imagens da barbearia na próxima atualização.

## Configuração pendente
No arquivo `app.js`, preencha `WHATSAPP_NUMBER` com o telefone oficial em formato internacional, somente números (ex.: 5511999999999). O formulário prepara o resumo do pedido e abre a conversa quando o número estiver configurado.

Os preços, endereço, horários e contatos exibidos como provisórios devem ser atualizados com as informações oficiais antes da divulgação.
